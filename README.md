# MyControl — этап 1

Личный диспетчер для iPhone: React, TypeScript, Vite, Dexie/IndexedDB, Lucide и Workbox. Первый запуск пустой, примеры включаются отдельно в настройках. Финансы и Saby относятся к следующим этапам и не имитируются фиктивными показателями.

## Возможности

Создание, редактирование, выполнение и удаление задач; категории и приоритеты; сегодня, завтра, следующие 7 дней, просроченные и история; поиск; календарь; повторения ежедневно, еженедельно, ежемесячно, по дням недели и с интервалом. Следующий повтор появляется после выполнения текущего, а не загружается в календарь заранее. Просроченные повторения сохраняют расписание: выполнение не переносит их относительно сегодняшней даты. В коротком месяце используется последний день, затем исходное число восстанавливается.

JSON-копии содержат все задачи и настройки этапа 1. Восстановление проверяет формат, версию, даты и дубликаты и выполняется транзакционно с заменой данных, после подтверждения. Экспорт ICS создаёт события с правилами повторения для Apple «Календаря». Повторный импорт может создать дубликаты, двусторонней синхронизации нет. Прямой импорт в Apple «Напоминания» не реализован.

Данные не отправляются на сервер, нет трекеров и внешних CDN. JSON-копии не зашифрованы — храните их приватно. iOS может очищать локальное хранилище. Регулярно сохраняйте резервные копии в «Файлы» и проверяйте наличие файла. Метка выгрузки не гарантирует, что файл сохранён.

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес в Safari.
2. В настройках MyControl дождитесь готовности офлайн-кеша.
3. «Поделиться» → «На экран Домой» → «Добавить». Если предлагается «Открывать как веб-приложение», включите.
4. Откройте новую иконку с интернетом, затем проверьте запуск в авиарежиме.
5. Работайте преимущественно из установленного приложения: Safari и установленный PWA могут иметь разные хранилища. Для переноса используйте JSON-копию.

Веб-приложение не обещает фоновые локальные уведомления iOS без серверного отправителя. Сейчас есть отметка просрочки при открытии и экспорт ICS. Для системных уведомлений добавьте события в «Календарь» и настройте оповещения там. `src/reminders.ts` определяет каналы напоминаний для дальнейшего расширения.

## GitHub Pages

Код располагается в корне репозитория. `.github/workflows/pages.yml` проверяет тесты, собирает приложение с базовым путём репозитория, запускает браузерные проверки и публикует `dist`.

Если настройку Pages нельзя выполнить автоматически: в Safari откройте репозиторий → Settings → Pages → Source → GitHub Actions. Затем Actions → «Проверка и публикация MyControl» → Run workflow. Публикация подтверждена только после зелёного deploy и открытия итоговой ссылки.

Для локальной разработки и CI: Node 22+, `npm ci`, `npm test`, `npm run build`, `npx playwright install chromium`, `npm run test:e2e`. Для системного Chromium можно задать `PLAYWRIGHT_EXECUTABLE_PATH`. `npm run dev` — разработка, `npm run preview` — production и Service Worker. `BASE_PATH=/mycontrol/ npm run build` — сборка для подпапки.

## Обновления

Схема Dexie имеет версию 1, формат копии — 1. Service Worker не удаляет IndexedDB. Несовместимые копии отклоняются целиком. Новые таблицы добавлять новой версией Dexie без удаления базы. Перед потенциально опасной миграцией сначала выпустить совместимую версию с предупреждением и экспортом. Текущий интерфейс обновления предлагает скачать копию перед активацией новой версии.

Следующие этапы: финансовый учёт (закупки отдельно от себестоимости и прибыли), сотрудники и товары, затем универсальный импорт CSV/XLSX с сопоставлением реальных файлов Saby. Сейчас эти модули не реализованы.

## Проверка текущей версии

Проверены production-сборка, 10 тестов логики и 3 браузерных сценария Chromium в мобильном размере 390×844: CRUD и история, перезапуск с сохранением задач, офлайн-перезагрузка, календарь, JSON экспорт/восстановление, тёмная тема и отсутствие горизонтальной прокрутки. Браузерные сценарии проходят со сборкой и Service Worker в подпапке `/mycontrol/`. Есть снимки iPhone-размера и широкого экрана. На физическом iPhone/Safari требуется финальная проверка установки после публикации.
